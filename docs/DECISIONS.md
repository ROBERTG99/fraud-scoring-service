| D-008 | 2026-10-16 | Isotonic calibration (fit on valid) is post-processed so its piecewise-linear map has slope ≤ 10: near-vertical steps are spread to the right. | D-010 | 2026-10-16 | `FRAUD_OPENAI_MODEL` defaults to `gpt-6-luna` (Responses API, strict JSON schema). | `gpt-5.4-mini`; GPT-5.6 family names. | OpenAI's docs (search on 2026-10-16) describe GPT-6 Luna as the most efficient model for high-volume tasks with structured outputs on `v1/responses` at USD 0.10 / 0.50 per 1M tokens; the installed `openai` SDK lists `gpt-6-luna` among its model IDs. The docs host was unreachable for a full read and api.openai.com is blocked, so the adapter is tested against documented-shape fixtures only. Override with the env var. |
| D-011 | 2026-10-16 | LLM adapter fixtures (`tests/fixtures/llm/adapters/`) are hand-authored in the documented response shapes and labelled as such; cassettes produced offline carry `"recorded": false`. | Claim recorded cassettes. | No provider key in the build environment; spec §0 rule 6 forbids presenting invented data as recorded. `make record-fixtures` records real ones when a key exists. |
| D-012 | 2026-10-16 | When both the model and features are unavailable, the degraded band uses the lower of the two floors (`features_unavailable.review_min_amount_minor`, 5,000) and both reason codes are emitted (`MODEL_UNAVAILABLE`, `FEATURES_UNAVAILABLE`). | Use the model floor (20,000). | §4.4 defines each floor separately but not the combination; the lower floor is the conservative (REVIEW-biased) choice FR-8 asks for. |
| D-013 | 2026-10-16 | When Redis is unavailable the scorer does not call the model: score -1, `model_version = "none"`, reason `FEATURES_UNAVAILABLE` only, degraded band by amount. | Score the fallback vector with the model. | The band is replaced in degraded mode anyway (§4.4), and skipping the call keeps the 45 ms budget for Postgres and idempotency. |
| D-014 | 2026-10-16 | The LLM gateway retries only 408, 409, 429, 5xx, timeouts and connection errors. Invalid JSON or schema violations are not retried on the same provider; the call moves to `FRAUD_SUMMARY_FALLBACK_PROVIDER` if set, else the summary is `fallback`. | Re-sample on invalid output. | Appendix B and `.claude/rules/llm-code.md`; found by the M2 review. |
| D-015 | 2026-10-16 | Cost accounting prices cache writes at 1.25x and cache reads at 0.1x of the input price (`config/llm_routes.yaml` list prices). | Count all input tokens at the list price. | Matches provider billing for prompt caching; found by the M2 review. |
| D-016 | 2026-10-16 | Rule expressions compile with all expr builtins disabled except `min`, `max`, `abs`; a rule that errors at runtime is a non-match, counted in `fraud_rule_errors_total` and logged once; a rules file whose name and YAML `version` differ is rejected. | Allow all builtins; fail the request on a rule error. | Rules must be deterministic functions of the feature env; a broken rule must not take scoring down. |
| D-017 | 2026-10-16 | Redis idempotency first (`fr:idem:score:{tx_id}`, SET NX, 24 h); when Redis errors, the scorer looks the transaction up in Postgres (`decisions.transaction_id` UNIQUE). Concurrent duplicates are resolved by `INSERT … ON CONFLICT DO NOTHING`: the losing request returns the stored decision. | Distributed lock per transaction. | §4.7 "idempotency via Postgres" when Redis is down; no lock on the hot path. |
| D-018 | 2026-10-16 | Go dependencies are pinned to versions whose `go` directive is ≤ 1.24 (`GOTOOLCHAIN=local` in the Makefile); kfake is pinned to commit `da75e26e4cf5`. | Latest modules (require Go 1.26). | §16 fixes `golang:1.24` images and the preinstalled toolchain is 1.24.7. |
