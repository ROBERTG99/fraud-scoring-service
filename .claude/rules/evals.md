# Eval rules

- Datasets are generated by `scripts/gen_eval_sets.py` with seed 7; test partitions are never edited by hand.
- Tune on dev splits only. Report every metric with its threshold and the command that produced it.
- `evals/REPORT.md` is generated by `scripts/build_report.py`; never edit it by hand.
- Baselines in `evals/reports/baseline/` change only with a recorded reason in `docs/DECISIONS.md`.
